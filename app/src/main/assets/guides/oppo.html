OPPO / 一加 / realme（ColorOS）图文引导

ColorOS 16 叫「隐私」，17 起叫「隐私与安全」。一加/realme 入口名可能不同。

1. 广告跟踪（OAID）

设置 → 隐私（/隐私与安全）→ 设备标识与广告 → 广告跟踪

关：每个 App 一个开关，没有总开关，数量可能上百，要翻 5 屏，整页全关。

⚠️ 新装的 App 默认开，装了新 App 要回来关一次。部分机型点搜索结果不跳转，走面板路径。

2. 软件商店

软件商店 → 我的 → 右上齿轮（或 oppo.intent.action.APP_SETTINGS 直达）
位置开关操作
服务管理首页悬浮活动图标、首页活动弹窗、首页顶部轮播卡片、底部活动专区、游戏专区、签到福利等 30+ 项全关
服务管理帮助与客服、应用安全、应用工具、存储空间清理、下载更新保留
隐私 → 个性化推荐个性化推荐关
⚠️ 一加/realme 商店没有「服务管理」，个性化推荐在「账号与隐私 → 隐私授权管理 → 个性化推荐」。

3. 浏览器

浏览器设置（直达 com.heytap.browser/.settings.component.BrowserPreferencesPage）
位置开关操作
主页设置 → 页面布局选「简洁」关资讯流
隐私 → 广告管理开屏广告、资讯列表广告关
隐私 → 个性化管理个性化推荐关
隐私 → 广告管理摇一摇广告点不动属正常（系统置灰）
⚠️ realme 简洁模式浏览器没有底部「我的」也没有菜单，只能直达 BrowserPreferencesPage。

4. 下拉搜索

桌面下滑 → 搜索页底部「设置」（或 scheme gs://search/setting 直达）
子页关保留
搜索范围榜单、小说、购物、个性化推荐、精选资讯APP内搜索、搜索建议、AI搜索、便捷服务
首页卡片管理未下载应用推荐、应用建议小卡、探索发现、活动皮肤应用建议、本机资产推荐、便捷服务
功能管理搜索框提示词—
账号与隐私 → 隐私个性化推荐—
⚠️ SearchSettingActivity 未导出，必须用 scheme gs://search/setting。com.heytap.quicksearchbox 被挂起时 scheme 会落到「应用已被暂停」页，运行前不能挂它。
⚠️ 「APP内搜索」必须开着，关了搜不到本机应用。搜索页顶部提示「搜索结果受限」不要点「去开启」。

5. 主题商店

主题商店 → 我的 → 设置（右上）

关：服务管理→消息与广告（消息通知、开屏广告）；隐私→个性化推荐设置

⚠️ 「设置」入口随版本变：17.22.0beta2 是「设置,有1条新通知」文字行，要按包含匹配。「个性化推荐设置」点下去先弹确认框，确认后页面退回，回读前要重新进一次。

6. 小布建议

设置 → OPPO AI（/NEXT AI）→ 小布建议 → 内容资讯 → 资讯服务

关：资讯服务、视界日报、小红书资讯

保留：快递、航班、日程提醒、商圈服务、赛事、出行

⚠️ 「内容资讯」是分组标题点不动，真正入口是下面的「资讯服务」行（显示「未开启」），点进去二级页才有开关。realme 入口叫「NEXT AI」。

7. 负一屏（速览）

桌面左滑 → 左上头像 → 设置

关：搜索框提示词、热点资讯、推荐服务→轮播推荐选「不显示」、隐私→个性化推荐

保留：推荐服务总开关（关了会删天气、步数、清理卡片）、服务动态、快捷服务

⚠️ 负一屏设置页受 OPPO_COMPONENT_SAFE 私有权限保护，adb/am start 都被拒，只能手动：桌面左滑 → 左上头像 → 设置。

8. 营销通知

设置 → 通知与状态栏 → 通知管理 → 选 App → 点渠道名

关：每个 App 里叫「内容与营销」的渠道；系统消息「精彩推荐」、云服务「专享优惠」「权益福利」、钱包「福利通知」、视频「重要营销信息」、负一屏「最新资讯通知」

保留：订单、物流、更新、安全、聊天、快递、天气预警

⚠️ 通知页宿主 ColorOS 14 起是 com.oplus.notificationmanager，11/12 是 com.coloros.notificationmanager。com.heytap.mcs 的「精彩推荐」「news」渠道开关是灰的，系统锁定。

9. 广告包与快应用（增强模式）

包作用挂起后
com.opos.adsOPPO 广告服务正常
com.heytap.pictorial乐划锁屏锁屏杂志消失
com.oppo.instant.local.service快应用本地服务快递卡片与详情页正常
⚠️ 绝对不能挂：com.oplus.appdetail（挂了所有第三方安装/卸载永久卡死）、com.heytap.quicksearchbox（下拉搜索）、com.coloros.assistantscreen（负一屏）、应用商店、com.nearme.instant.platform（快应用平台，挂了负一屏快递详情打不开）。
⚠️ 乐划应先在应用内关闭锁屏功能再挂，先挂会无法进设置关功能。

OPPO 的坑

⚠️ com.oplus.appdetail 不能挂：挂起它会导致所有第三方安装永久卡在「正在安装」，卸载也一样。已被别的工具挂的要用 unsuspend 还原。
⚠️ 摇一摇广告点不动：浏览器/商店「摇一摇广告」在上级开关关掉后仍显示开且 enabled=false，系统置灰，点不动属正常，不算独立关闭。
⚠️ 负一屏 adb 起不来：受 OPPO_COMPONENT_SAFE 私有权限保护，只能手动。
⚠️ 「设置,有1条新通知」：主题/游戏中心设置入口带通知角标，精确匹配找不到，要按包含匹配。
